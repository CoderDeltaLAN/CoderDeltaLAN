## What I build

CDLAN is focused on practical systems with clear limits.

I work around:

- process diagnosis and operational clarity;
- RAG and document intelligence;
- AI agents and assistants with explicit boundaries;
- N8N automation and workflow design;
- static professional websites without unnecessary backend complexity;
- technical documentation and maintainable handover.

I do not present AI as magic. I prefer systems that can be explained, tested, documented and maintained.

## Security boundary

This profile repository is public presentation only.

It must not contain:

- secrets;
- API keys;
- credentials;
- personal photos;
- private prompts;
- client data;
- private logs;
- backend internals;
- exported automations;
- environment files.

Current repository baseline:

- `SECURITY.md` present;
- `scripts/verify.sh` present;
- GitHub Actions `Verify` workflow present;
- manual `workflow_dispatch` enabled;
- `main` branch protected;
- required status check: `verify`;
- force push blocked;
- branch deletion blocked.

For security-related reports, see [`SECURITY.md`](SECURITY.md).

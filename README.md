## What I build

CDLAN is focused on practical systems with clear limits.

I work around:

- process diagnosis and operational clarity;
- RAG and document intelligence;
- AI assistants and agents with explicit boundaries;
- n8n automation and workflow design;
- static professional websites without unnecessary backend complexity;
- technical documentation and maintainable handover.

I do not present AI as magic. I prefer systems that can be explained, tested, documented and maintained.

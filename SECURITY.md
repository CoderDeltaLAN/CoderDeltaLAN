# Security Policy

This repository is the public GitHub profile for Delta / CoderDeltaLAN / CDLAN.

It is presentation material only. It must stay small, public-safe and easy to audit.

## Boundary

This repository must not contain:

- secrets;
- API keys;
- credentials;
- private prompts;
- private logs;
- personal photos;
- client material;
- environment files;
- backend internals;
- exported private automations;
- experimental scheduled jobs.

## Allowed content

Allowed content is limited to:

- public README content;
- local SVG profile assets;
- one local verification script;
- one minimal GitHub Actions verification workflow;
- this security policy.

## Reporting

Do not report sensitive exposure publicly in issues, pull requests or public comments.

For professional or security-related contact, use the portfolio:

https://coderdeltalan.github.io/cdlan-portfolio/

## Operating rule

`main` must remain clean, protected and verified.

No change should enter the public profile unless it is small, reviewed, locally checked and safe to expose.
